# Problem 1

## Read, clean and describe

``` r
options(lifecycle_verbosity = "quiet")

NYC_df = read.csv(
  "./data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv",
  na = c("",".","NA")
  ) |>
  janitor::clean_names()|>
  select(line, station_name, station_latitude, station_longitude, route1:route11, entry, vending, entrance_type, ada)|>
    mutate( entry =
      case_match(
        entry,
        "YES" ~ 1,
        "NO" ~ 0
      )
    )
```

This NYC subway dataset from MTA contains line, station, name, station
latitude / longitude, routes served, entry, vending, entrance type, and
ADA compliance information.

So far, I have read the original dataset, defined the missing data as
NA, used janitor to make variable names cleaner, selected the variables
wanted as mentioned, and cnverted the entry from chharacter to a logical
variable\[ YES became 1, NO became 0\].

Now I got a dataset called NYC_df with 1868 rows and 19 columns.

These data are not fully tidy. Each row represents one station
entrance/exit, and most variables form their own columns. However, the
routes served by each station are spread across multiple columns (route1
to route11). According to tidy data principles, each variable should
form a single column. Having the same type of information (route)
repeated across many columns violates this rule.
